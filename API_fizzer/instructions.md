## How to use
### Installation Process
1. Download the script
2. make it executable with `sudo chmod u+x api_fuzzer.py`
3. Link it or copy it to the $PATH

### Usage
`api_fuzzer.py [url] [wordlist]`

### Response

```

word    200
name    200
```

**Note: This script is made for only to respond with 200 Status code**
